# Culture and Social Runtime Contract

The authoritative tick order for human social cognition is:

1. biological/health and civilization state advances;
2. individual cognition observes and records action/outcome memory;
3. `SocialRuntime` evaluates deterministic pairwise interactions and updates relationships/groups;
4. `CultureRuntime` transfers learned knowledge only through sufficiently trusted friendships;
5. shared knowledge adopted by multiple living agents becomes an explicit tradition.

Both runtimes are deterministic, bounded, and independent of external services. They operate on the same `SimulationState` and simulation tick, so replaying the same initial state produces the same social/cultural result.
