# Finance, Education and AI-Assisted Humans

Genesis treats financial capability as a civilization institution, not as an autonomous trading bot.

## Domain separation

- `finance.exchange` owns assets, portfolios, orders and deterministic settlement.
- `finance.trading` owns trader profiles, a free training academy and company capital limits.
- `knowledge` remains the authoritative evidence system. Trading lessons become institutionally reusable only after the existing independent-evidence verification gate.
- `education.ai_assistant` is a provider-neutral boundary. The core simulation performs no network calls and never grants an external model direct access to private agent memory.

## Human-first decision model

A simulated person remains the decision maker. An AI provider can teach, explain and analyze authorized institutional lessons. It does not become an autonomous trader by virtue of the adapter.

## Memory flow

`experience -> evidence -> verified knowledge -> trading academy -> authorized AI context -> next-generation education`.

Private episodic conversations remain separate from institutional knowledge. An external provider receives only explicitly authorized lessons through `AIProvider`.

## Financial safety boundary

The simulation exchange enforces cash/position invariants and company capital limits. Real broker/network adapters are intentionally outside the deterministic core. Any future real-world adapter must sit behind an independent risk gateway, audit trail and explicit authorization boundary.

## Performance and determinism

Experience and assistant histories are bounded. Exchange trade history is bounded. Lesson publication is deterministic by repository ordering. No network or database dependency is introduced into the simulation core.
