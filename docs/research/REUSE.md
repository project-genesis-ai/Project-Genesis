# Reuse and Research Policy

Genesis reuses mature open-source and research software where it is a better fit than reimplementation.

## Current references

- Mesa: agent-based modeling and scheduling patterns.
- Ecosim Toolbox: ecosystem, trophic, terrain, and organism interaction reference.
- Box2D/pybox2d: reference for established rigid-body simulation patterns; not the authoritative planetary physics model.

## Policy

1. Check license compatibility before importing code.
2. Prefer stable libraries over copying implementation code.
3. Wrap external systems behind Genesis interfaces.
4. Keep scientific equations and assumptions explicit and testable.
5. Preserve attribution and license notices where required.
6. Do not blindly copy a repository into Genesis.
